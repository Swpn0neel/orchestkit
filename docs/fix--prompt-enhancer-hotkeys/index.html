ORCHESTKIT LAB · MODS · PROMPT ENHANCER

Press Enhance, Undo and Send from the keyboard

In the default terminal mode, Claude Code does not ask the terminal for mouse clicks, so a click on the band above the prompt selected text and never pressed a button. There was also no key for any button and no hint. Version 0.1.1 gives each button a key and draws one dim line that says how to reach them.

✨ Prompt Enhancer [ - ]
[ Enhance ] [ Undo ] [ Send ]
Enhanced below: edit it, then Send (or Enter). Undo puts your original back.
Keys: ctrl+x tab, then e / u / s

The keys come from the button hotkey property in the Claude Code 2.1.304 mod API. A click still works where the terminal reports clicks (the fullscreen mode). Not yet checked by hand in a live pane; the tests check the keys and the hint on the drawn band.
