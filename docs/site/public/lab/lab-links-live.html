PR Lab links must serve a page

Verdict: the PR Playground gate checked that a page existed under docs/<branch-slug>/ and that the PR body said "playground". It never checked that the /lab/<slug>.html link in the body is a page the merge publishes, and a PR it exempted got no check at all. A new step now checks every Lab link on every PR, and a post-merge job requires each one to answer 200.
